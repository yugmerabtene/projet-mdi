LAB — Page web conteneurisée

Une page web,
une image Docker,
zéro installation côté client.

Ce que vous voyez est servi par nginx, installé dans un conteneur Docker. Le serveur web est isolé du système hôte : le supprimer revient à supprimer un dossier.

Serveur web
nginx
Exécution
conteneur non privilégié
Dépendances front
aucune

État du serveur

Le bouton ci-dessous interroge la route /api/infos. Cette route est définie dans la configuration nginx, à l'intérieur de l'image : aucun programme serveur n'est nécessaire.

Ce que fait l'image

  • Sert les fichiers statiques en lecture seule.
  • Expose une route JSON minimale pour la démonstration.
  • Répond à /healthz pour l'oracle de santé (healthcheck) de Docker.
  • S'exécute avec un utilisateur non privilégié et n'occupe aucun port privilégié du système hôte.
